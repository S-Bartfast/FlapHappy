They include provisional estimates and user-configured defaults; they are not

Reading the tables:
  * Light and Heavy are loaded flying weights in kg, not empty weight and not
    necessarily MTOW. MTOW is separately quoted from the exact WSG reference.
  * All transition speeds are IAS. WSG's SQLite storage uses integer
    hundredths of metres per second (e.g. 2361 = 23.61 m/s), NOT integer
    km/h. The public catalog v2 still transmits band starts in knots.
    The m/s columns below reconstruct the canonical decimal m/s values to
    two decimals; km/h shows the exact metric equivalent of those values.
    The appendix preserves the public JSON knot decimals verbatim. The
    shared WSG profile exchange JSON declares kg and km/h IAS; storage,
    catalog wire units and exchange-file units are distinct.
  * VNE is the separate WSG reference TAS value in km/h, not an IAS limit.
  * Starting detents use the catalog baseline of zero; that zero is not a
    measured stall speed or an independent transition. Final detent has no
    extra table IAS ceiling. Native simulator handle indices are zero-based.
  * A transition with Excluded is explicitly hidden by the WSG default; its
    published IAS is still recorded below and is not missing. Missing IAS is
    marked --, never replaced by zero or inferred. Not specified is an absent
    visibility flag, separate from an explicit Shown flag.
  * Stall IAS endpoints are listed only if the catalog publishes them; an
    unavailable endpoint is not a zero and must not be inferred from another
    speed, the first divider, MTOW or VNE.
  * Source links identify exact matching variants. Some WSG reference queries
    require the published aircraft alias instead of the canonical key; each
    returned gliderKey was checked against the canonical variant listed.

Native Flap Happy field mapping (profile schema flaphappy.profile/3):
  Baseline native JSON stores decimal m/s, not scaled integers. For the
  published AS33-18-GF 5 -> N transition, the fragment is:
    {"no_ballast_ms": 26.39, "max_ballast_ms": 29.72}
  The same field names are used under vs_min for stall IAS, when supplied.
  PR #1 (c90f611) additionally supports optional loaded reference weights:
    "weight_kg": {"light": 485, "heavy": 600}
  Both valid weights select live weight; older profiles without both use
  manual ballast. These fragments illustrate units/fields only, not a complete
  valid native import. Match ordered native flap handles and visibility rules
  separately; do not fill missing Vs or map published TAS VNE to vne_ms IAS.

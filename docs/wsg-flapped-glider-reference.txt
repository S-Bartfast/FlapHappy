These are current WSG.org starter values for the named MSFS add-ons and variants.
They include provisional estimates and user-configured defaults; they are not
verified flight-test measurements, aircraft flight-manual data, placards, or
airworthiness or operational guidance for real aircraft. Do not treat them as
manufacturer-approved values or install them automatically.

Reading the tables:
  * Light and Heavy are loaded flying weights in kg, not empty weight and not
    necessarily MTOW. MTOW is separately quoted from the exact WSG reference.
  * All transition speeds are IAS. The metric column is the published wire IAS
    multiplied by exactly 1.852, rounded to six decimal places for readability.
    The wire appendix under each table retains the source JSON knot numbers
    exactly, including the full decimal representations returned by the API.
  * VNE is the separate WSG reference TAS value in km/h, not an IAS limit.
  * Starting detents use the catalog baseline of zero; that zero is not a
    measured stall speed or an independent transition. Final detent has no
    extra table IAS ceiling. Native simulator handle indices are zero-based.
  * A transition with Excluded is explicitly hidden by the WSG default; its
    published IAS is still recorded below and is not missing. Missing IAS is
    marked --, never replaced by zero or inferred. Not specified is an absent
    visibility flag, separate from an explicit Shown flag.
  * Stall IAS endpoints are listed only if the catalog publishes them; an
    unavailable endpoint is not a zero and must not be inferred from another
    speed, the first divider, MTOW or VNE.
  * Source links identify exact matching variants. Some WSG reference queries
    require the published aircraft alias instead of the canonical key; each
    returned gliderKey was checked against the canonical variant listed.
